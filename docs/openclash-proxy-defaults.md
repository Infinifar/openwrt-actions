# Proxy 默认与选择持久化

2026-10-28：三份公开模板的 `Proxy` 保持手动 `select`，把已存在的美国国家组移到首项，并在末尾增加一次 `US-AI`；DIRECT 和其余原有选项的相对顺序保留。最终覆写采用相同策略，不新增不存在的美国组，不创建或改写其他类型的 Proxy。

- AI 仍手动选国家，默认美国；Google 仍默认跟随 Proxy。它们自己的列表和默认值不因此改变。
- US-AI 的圣何塞 5/6/7 筛选、手动选节点、空组拒绝及持久化保持不变；公开订阅仍为空，没有预置真实节点。
- Auto 模板中的美国国家组仍会自动选择具体节点；要固定节点，应手动选择 US-AI 再选择它的具体节点。本改动不会把自动国家组改成手动。
- 三份模板保留 `profile.store-selected: true`。美国排在首位只决定没有历史选择时的默认值；已有 Mihomo 选择缓存优先生效，不能据此宣称任何现役设备已经切换到美国。
- 如需立即迁移自行部署的设备，只应通过面板或已认证控制器更改 Proxy 选择，并复核实际出口。不要删除全局选择缓存、订阅或身份文件，也不要重启无关服务。

回归覆盖旧的 DIRECT-first 列表、US-AI 缺失/重复、美国组缺失及非手动/无 Proxy 的配置；重复执行保持幂等。服务默认开关、管理监听范围、身份和订阅的脱敏边界均不改变。
